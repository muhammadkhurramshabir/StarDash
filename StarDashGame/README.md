# Star Dash Android Game

A small offline arcade game. Move left/right to dodge asteroids and collect glowing stars. Best score is saved locally.

## Build an APK for free
1. Install Android Studio (free) from https://developer.android.com/studio
2. Open this `StarDashGame` folder as an existing project.
3. Let Android Studio download the Android Gradle Plugin and Android SDK components if prompted.
4. Select **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. The debug APK is normally created at `app/build/outputs/apk/debug/app-debug.apk`.

## Quick browser preview
Open `app/src/main/assets/index.html` in a modern browser. The game is self-contained and works offline after opening.

## Notes
- Package ID: `com.gocuriousmind.stardash`
- Minimum Android version: Android 6.0 (API 23)
- No account, backend, ads, or network permission required.
- This source project has not been compiled or device-tested in this environment. Android Studio must build the APK.
